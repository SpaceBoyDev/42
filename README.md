# 42 Cursus

This repository gathers my 42 cursus projects, a hands-on program focused on low-level programming, algorithms, teamwork, and software development in C/C++ through project-based learning.

Este repositorio reúne mis proyectos del cursus de 42, una formación práctica enfocada en programación de bajo nivel, algoritmia, trabajo en equipo y desarrollo de software en C/C++ mediante aprendizaje basado en proyectos.
